## Примечания

- Суффиксы `-1`, `-2`, `-3` в именах папок — номера попыток/раундов прохождения проекта.
- Внутри проектов решения обычно лежат в `src/`, учебные материалы школы — в `materials/`.
- Крупные датасеты в репозиторий не включены: они исключены через `.gitignore`, как и в исходных репозиториях GitLab.
- Решения взяты из наиболее актуальной ветки каждого исходного репозитория (обычно `develop`).
